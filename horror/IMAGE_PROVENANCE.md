# Dark Archive image provenance

All Dark Archive visuals are original AI-generated artistic reconstructions created by this repository's GitHub Actions workflow. They are not copied archival photographs.

- Generator: `scripts/horror/gen_stills.py`
- Model: `SimianLuo/LCM_Dreamshaper_v7`
- Model license recorded beside every generated image in `MODEL.txt`
- Historical sources in video descriptions support the story facts, not ownership of the generated visuals
- Every video description discloses that its scenes are AI-generated artistic reconstructions
